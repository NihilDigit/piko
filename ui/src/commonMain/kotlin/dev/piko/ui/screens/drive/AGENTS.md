# 网盘页

通用界面约定见 `../../../../../../../AGENTS.md`（即 `ui/AGENTS.md`），核心列表状态位于 `shared/.../shared/state/DriveScreenState.kt`。宽窗口与窄窗口严格按实际可用净宽高与内容容量划分，不按平台划分；文件浏览、链接导入与查重共享同一套账号工作集合（`WorkspaceContexts` 与 `DriveWorkspace`），触屏、鼠标与键盘可随时混合操作。

## 视图、特殊位置与探索模式

### 瀑布流画布（`GallerySession` 与 `GalleryCanvas`）

- **作用域与增量发现**：普通目录视图切换保留「列表」与「海报墙」两种当前层视图；「瀑布流」与「信息流」同为面向当前目录子树（或多选模式下显式选定的视频集合）的探索入口。`GallerySession` 归属 `DriveBrowserSession`，切换标签、切往任务页或调整窗口尺寸均保留已发现列表与浏览进度；仅在切换目录、开启搜索或显式确认关闭时退出。普通目录通过 `VideoDiscovery` 与仓库 `listBrowsable` 逐层发现视频（沿用归档虚拟条目合并与内部目录隐藏规则；包含短视频，不套用信息流的 60 秒时长门槛或启发式样片折叠）。每次请求至多扫描 16 个目录、追加 48 个视频，视口接近尾部时自动触发下一批，不设条目计数与手动「继续查找」按钮；失败目录保留为可重试状态，不计作扫描完成。候选按文件 ID 及 `GCID + 大小` 去重后经 `selectSpreadCandidates` 分散目录与作品，不按转码状态或根层优先排序。仓库 `folderChanges` 到达时增量刷新受影响目录，保留已展示顺序并将新增视频追加至末尾，移出当前子树的条目即时剔除。
- **循环带几何布局与封面零解码预取**：`GalleryCanvasLayout` 负责纯几何计算与 occurrence key，卡片等宽，按视频宽高或实测封面比例归入横向 `16:9`（含 `21:9`）、竖向 `9:16` 与方形 `1:1` 三种形状；每栏按无限循环带连续滚动，相邻栏错开半个横向卡片节距，内容不足时仅补淡色品牌 Glyph 几何占位（不画底色与边框），仅组合当前视口及每栏上下各一张缓冲卡片。首屏未滚动前实测封面比例可修正初始几何，一旦开始滚动、追加候选或从播放器返回恢复锚点（`GalleryAnchor`）后，比例更新仅作用于未访问区间，已浏览区域绝不重排。封面预取（`GalleryCanvas`）带轻微防抖并跳过当前视口内正由 `AsyncImage` 高优加载的卡片：已知宽高比的条目使用 Coil `BlackholeDecoder` 配合 `CachePolicy.READ_ONLY` 仅预热磁盘缓存，跳过位图 CPU 解码；未知宽高比的条目仅按小尺寸探测像素解码学习比例，同时桌面端 `DesktopImageLoader` 已调高单主机并发上限以消除高延迟线路排队。卡片底部标注文件名与来自 `FolderIndex` 的父目录名；跨子目录视频的操作菜单置顶提供「在网盘中显示」，递归视频的命令动作读取 `GallerySession` 补充列表中的真实父目录，绝不将递归发现列表写回普通目录的 `state.files`。

### 资料库（`Screen.Library`）与压缩包内浏览（`ArchiveLocation`）

- **资料库**：最近添加、星标（自动合并服务端星标真实文件与 `VaultStars` 自管的星标归档虚拟条目）、播放历史与回收站作为应用返回栈中的 `Screen.Library` 独立压栈，各自拥有独立的 `DriveBrowserSession` 保存路径栈、历史、多选与滚动锚点，不改写工作区文件标签位置，返回即回到来源页。资料库根层使用 `DriveLibrary` 虚拟路径拉取对应接口，禁止新建、上传、粘贴或拖放写入；资料库内的真实文件保留「复制到…」能力；最近添加与播放历史支持「移除记录」，回收站仅提供「恢复」与「彻底删除」（单击回收站条目弹出操作面板而不直接执行单一动作）。「在网盘中显示」压入独立定位浏览页或跳回主文件区高亮目标。「我的分享」列举分享链接而非文件，由独立页面 `Screen.MyShares` 承载。
- **压缩包只读浏览**：单击非分卷的 `zip`、`rar`、`7z` 直接作为虚拟位置（`ArchiveLocation`，ID 前缀 `piko-archive:`，携带包文件 ID、GCID 与包内相对路径）进入浏览，不再直接触发整包下载（分卷压缩包因服务端不支持列出与解压，仍走下载）。状态由进程级 `ArchiveBrowser` 持有，已验证密码与已列出层级不随页面重建丢失；需要密码时先静默逐个尝试 `ArchivePasswordVault` 中已保存的密码，全部失配才弹窗询问，取消输入即退出该包。持久化文件标签与最近访问路径时自动截断至压缩包外层父目录，重启应用不停留在包内。包内条目仅支持打开、下载单文件与解压所选项（页面主操作为「全部解压」，落点为压缩包同级目录）；打开或下载包内文件与归档条目共用按 GCID 租约借出链路（`LeasedFile`），从未在服务端解压过的压缩包首次借出文件时自动执行一次数秒的引导预热（`ArchiveRepository.prime`，延迟 400ms 显示「正在读取压缩包内容…」提示，就绪即收起），此后同一包内文件均可直接按 GCID 秒借。

### 查重报告、批量移入回收站与按番号子树重命名

- **查重上下文（`DuplicateSession`）**：每次发起查重均在 `WorkspaceContexts` 中建立拥有稳定 ID 的独立上下文（移动端对同一目录起点自动复用已有未关闭的查重会话），宽窗口经标签栏切换，窄窗口经标签总览进入完整工作页。切换页面或收起总览均不中断扫描，仅显式关闭该查重上下文（或切换账号）才停止扫描并释放报告。页眉提供「相同文件 / 不同版本」连体切换及当前分类计数，「选中建议移走项」主操作仅在「相同文件」分类下启用且仅作用于当前目录内的文件行（目录行仅用于导航，不参与勾选删除）。`DuplicateDirectoryListing` 按扫描快照的原目录筛选，进入叶子目录后复用常规文件名解析分组。
- **批量清理（`TrashSession`）与后台开始提示**：批量移入回收站由进程级 `TrashSession` 按每批 100 项提交服务端确认；提交后查重报告立即投影剔除所选项，整体进度统一在任务页的 `CleanupTaskCard` 中展示，不按批次重复弹提示，网盘页不叠加浮动进度卡。中途失败时未确认项退回查重报告，重试仅提交剩余项并合并至同一条撤销记录。服务端解压（`ArchiveExtractSession`）与归档/取消归档（`FolderVaultSession`）在后台启动时，当前活动网盘页会弹出一次「已开始解压」「已开始归档」或「已开始取消归档」即时 Snackbar 并附带「查看」按钮直达任务页；若任务在提示展示期间即迅速完成，该开始提示自动取消让位给带「撤销」的完成提示。
- **按番号规范命名文件夹（`CanonicalFolderRenameDialog`）**：在模态对话框内执行子树扫描（`CanonicalTreeScan`），扫描完毕即就地转为固定套用番号规范规则的批量重命名预览（`BatchRenameState` 的 `tree` 模式），支持逐项取消勾选或微调新名称，关闭对话框即放弃本次扫描，不创建后台会话或工作标签。单个带番号文件的规范命名不单独占用右键菜单项，直接集成在普通「重命名」对话框底部（预填规范名，已配置 MetaTube 时同一常驻行无缝切换为拉取片名按钮，保持对话框高度恒定）。

## 命令栏、顶栏、目录图与属性浮卡

### 命令栏与顶栏

- **宽窗口命令栏（`DriveCommands.kt`）**：命令栏仅放置**作用于当前目录位置**的命令：新建、粘贴、排序、类型筛选、查找重复（固定附带文字标签以区分「复制」图标）、按番号规范命名、多选模式下的全选（多选时左端「新建」替换为退出多选与已选计数）、刷新、视图切换与瀑布流、信息流开关、回到根目录主页按钮，最右端固定放置当前上下文的主操作（添加链接、清空回收站、全部解压、选中建议移走项等）。**作用于具体文件或文件夹的条目操作（剪切、复制、重命名、分享、下载、移动、解压、删除、恢复）一律不进入宽窗口命令栏**，无论单选或多选均统一通过右键菜单（桌面触屏与手写笔长按弹出同一菜单）与键盘快捷键触发，避免重复堆砌将位置命令挤入溢出菜单。所有位置命令的显隐由纯函数 `driveCommands` 唯一决定，空间不足时由 `AdaptiveBar` 按固定优先级收入「更多」，拖动窗口宽度时按钮顺序不跳变。窄窗口因触屏长按直接进入多选而不弹菜单，批量条目操作按 `itemCommands` 展示在多选顶栏及溢出菜单中。
- **地址栏与紧凑顶栏**：宽窗口顶栏采用文件管理器样式的后退、前进、上一级按钮配可交互地址栏（`DrivePathTitle`，每段面包屑支持点击跳转、悬停展开同级子目录菜单及接收内部文件拖放；位于资料库时首段显示资料库图标与名称且后方不带 `›` 分隔符）。窄窗口顶栏以当前目录名为主标题、当前滚动所在的结构化作品分区（`SectionJumper`，点击可快速跳往其他分区）为副标题，不重复堆叠横向面包屑；路径输入、最近访问、快速访问与前进命令通过窄窗口列表页眉菜单与路径面板完整提供。

### 浮动目录图（`FolderMap.kt` 与 `FolderMapAutoHide.kt`）

宽窗口下目录图作为普通 `Layout` 承载的浮动面板（`FloatingPanel`，不使用不抢焦点即收不到键盘事件的 `Popup`）悬于文件列表之上，展示从网盘根目录起始的懒加载树（同时列出文件夹、可作为位置展开的压缩包及文件；最内层目录文件超过 3 项时仅列前 3 项并附「还有 N 个文件」展开行；不含虚拟根行，标题栏过滤框左侧提供回到根目录的主页按钮）。窄窗口通过底部 Sheet 承载同一棵 `WorkspaceTreeRow` 目录树。点击树中文件会先导航至其父目录并高亮定位，再按列表单击规则打开（确保播放列表取自真实父目录）。目录图与仓库共享列表缓存并订阅 `folderChanges` 增量刷新。

宽窗口目录图的开关、钉住与自动收起行为及时间参数均经用户逐条手测定稿，**修改任何时序数值或状态转换前必须先征得用户确认**：

- **双独立偏好**：开关状态（`folderMapOpenFlow`，由标题栏 `×`、搜索框旁树形按钮、快捷键 `主修饰键+Shift+E` 或命令面板切换）与钉住状态（`folderMapPinnedFlow`，**仅**由标题栏钉住按钮切换，拖动、输入或点 `×` 关闭重开均绝不篡改钉住状态）作为两项独立的设备本地偏好跨重启保留。
- **停靠判定与自由浮动**：拖拽标题栏松手时，若面板左沿或右沿距列表同侧边缘不超过 `48dp` 即判定为停靠（窗口缩放后重判一次，拖拽途中不判定、不磁吸；停靠左沿则随左沿对齐），四边四角均可拖拽调大小（停靠侧的边与角除外，避免压住侧边把手）。拖至列表中间区域时面板常驻展示，不自动收起；未钉住的面板拖回边缘停靠后恢复自动收起。
- **贴边把手与自动收起时序（`FolderMapAutoHide.kt`，单测 `FolderMapAutoHideTest`）**：未钉住且处于停靠态的面板闲置时收起为贴靠列表同侧边缘（避让右侧滚动条）的实体容器色阴影把手，内含目录树图标并支持 `Tab` 聚焦（无障碍标签「展开目录图」）。
  - **悬停展开**：指针在打开区内静止满 `200ms` 才触发临时展开（移动超过 `6dp` 重新计时；按住鼠标按键时不计时，防止拖拽滚动条或框选途经边缘误触弹出）。点击把手、触屏轻点、顶栏按钮、快捷键、命令面板或在把手上按回车/空格亦可触发临时展开（键盘触发时焦点自动移入树内；从外部按钮主动唤出时须等指针首次进入保持区或面板发生交互后才启动离开倒计时，避免刚打开半秒即自动收回）。
  - **离开收起**：保持区为面板四周外扩 `24dp` 连同把手区域；指针离开保持区满 `500ms` 才收起，期间移回立即取消倒计时。正在拖拽移动或调整尺寸、面板内持有键盘焦点、过滤框内有文本或持有焦点期间均锁定不收起，条件解除后重新起算 `500ms`。收起后指针必须先完全离开打开区一次才重新武装悬停检测，防止停在边缘反复弹回。上述毫秒数为意图过滤阈值，不随「减少动画」归零（减少动画仅使 `167ms` 原位淡入位移 `PikoMotion.peekEnter` 与 `83ms` 淡出变为跳切）。收起期间面板离开组合以释放开销，但过滤词、高亮、滚动位置与 `bounds` 保留在 `FolderMapState` 中，属性卡片照常按其边界避让。
  - **键盘 `Esc` 与快捷键语义**：临时展开态下按 `Esc` 或快捷键为收起回把手（焦点在面板内时 `Esc` 先将焦点归还文件列表）；钉住态下按 `Esc` 仅归还焦点，按快捷键则等同于 `×` 彻底关闭目录图（保留钉住偏好不变）。开发版可通过 `JAVA_TOOL_OPTIONS=-Dpiko.debug.folder-map=true` 启动 `:desktopApp:run` 描绘打开区、保持区与倒计时调试叠层（正式带版本号构建自动忽略）。
- **已否决的历史形态（禁止回退）**：地址栏 `›` 呼出的迷你弹层（入口隐蔽）；嵌入左侧边栏（`240dp` 宽度无法容纳多层缩进）；在文件网格旁挤压出常驻第三栏（开关导致网格反复重排且形成双导航栏并列）；与把手共用同一容器形变伸缩的细轨（形变期间拖拽落点错位）。

### 条目操作、下载画质与属性卡片

- **条目操作单一来源（`DriveActions.kt`、`itemCommands`、`operationsOf`）**：所有动作的图标、文案、分档与分组仅在 `DriveActions.kt` 定义一次，可用性统一由 `DriveCommands.kt` 的 `itemCommands` 根据当前位置（`CommandPlace`）、选中条目状态与完全归档目录表（`fullyVaultedFolders`）纯函数计算，`DriveScreen` 的 `operationsOf` 统一组装右键菜单、底部操作面板与多选操作栏，宽窄窗口共享完整能力集合（包括文件夹查重、按番号规范命名、在新标签页打开、固定到快速访问、剪切/复制、资料库内真实文件复制到、归档与取消归档、复制或打开来源链接、复制下载直链、外部播放器打开）。多选包含可播放视频时额外提供「以瀑布流浏览所选视频」与「以信息流浏览所选视频」。部分归档文件夹同时保留「归档」与「取消归档」，完全归档文件夹仅显示「取消归档」；归档虚拟条目支持由 Piko 自管的星标、在清单内直接改名、下载原画、复制直链/来源、恢复到网盘及从清单移除。仅点击后仍需弹窗选择目标或参数的动作保留省略号（「移动到…」「复制到…」「下载指定画质…」「下载指定段落…」），普通「下载到本地」不带省略号。
- **下载与画质选择（`DownloadLauncher`）**：普通「下载到本地」直接使用本机默认下载画质偏好（未设置时按原画）立即入队并跳转任务页，文件夹直接生成可见的后台目录准备任务，绝不在入队前预先递归扫描目录以判断是否含视频。「下载指定画质…」作为独立菜单项，仅在用户主动点击时弹出 `DownloadQualityDialog`（即使已设默认画质亦照常询问；单视频列出实测各转码档与大小，多文件或文件夹仅列画质上限档位；勾选「以后按此画质直接下载」才更新默认偏好并在跳转后的任务页或当前播放器内弹出确认提示）。普通下载菜单项悬停时不探测转码档，仅「下载指定画质…」与「下载指定段落…」在指针悬停或按下时调用 `prefetchDownloadQualities` 预热。归档虚拟条目、压缩包内借出对象与导入预览条目仅支持原画下载，不提供指定画质。转码档不可读或已被移除时的错误提示必须明确点明服务端主体（「PikPak 的转码文件暂不可读」「PikPak 已不提供所选画质」），避免用户误判为客户端或本机网络故障而反复重试（详见 `shared/src/commonMain/kotlin/dev/piko/shared/download/AGENTS.md`）。
- **属性浮卡（`PropertiesPane`）**：通过右键菜单末组「属性」、空白处右键「属性」（查看当前目录）、`主修饰键+I`（macOS `⌘I`）或 Windows / Linux `Alt+Enter` 打开，锁定打开瞬间的目标快照（多选时统计项数、总大小与位置），后续列表焦点或勾选变化不联动刷新内容（一次仅开一张，对新目标触发属性时原地替换内容，保留当前浮窗位置，仅在超出视口时夹回）。宽窗口下由 `DetailHost` 与 `ItemPanelAnchors` 定位：右键菜单触发时置于按下坐标，快捷键或面板触发时贴靠焦点条目右侧（放不下则左侧），当前目录或命令面板触发时置于列表中央偏上；宽度随内容自适应（`280~440dp`），不支持拖拽改尺寸，内容超长时内部滚动（已否决跟随选中实时变化的常驻右侧属性栏与悬停详情小按钮）。

## 双名称体系（显示名与真实名称）

文件或文件夹可能同时具有解析出的结构化显示名（如将目录「动画」识别为作品名 `Frieren`、单集显示为 `01`）与网盘存储的真实文件名，单一数据源为 `DriveItemName`（`shared/.../state/DriveItemName.kt`，排版组件位于 `ItemNames.kt`，严禁手写 `folderViews[id]?.title ?: name`）：

- **辨识条目处使用显示名**（两者不同时在下方另起一行小字展示真实名称）：列表行与海报卡片（取 `title`，单集不重复冠以分区头已有的作品名）、底部操作面板头部、属性浮卡、拖放浮层标签、片段下载面板、归档确认框及归档进度与结果摘要（取 `heading`，如 `Frieren 01`）。
- **标识路径与写操作处一律使用真实名称**（`FolderIndex` 与持久化路径不掺入解析名）：顶栏地址栏、工作区标签标题、窄窗口目录标题、目录选择器、目录图、重命名输入框初始值（默认自动选中扩展名之前的主文件名）、资料库与搜索结果所在位置栏、移动/复制目标目录名、查重起点与按番号重命名对话框标题。文件名解析总开关关闭时全局统一显示真实名称。
- **搜索匹配范围**：当前目录内搜索（`listedName`）同时匹配解析显示名与真实名称；全盘搜索在 SDK 遍历与 `DriveTreeIndex` 中按真实名称（含 CJK 模糊匹配）检索。

## 鼠标、键盘与内部拖放

点击与键位遵循各桌面操作系统的原生文件管理器规范，网格空白背景提供独立右键菜单（视图模式、瀑布流开关、显示文件扩展名、刷新、粘贴、新建文件夹、上传文件/文件夹、添加链接、全选、当前目录属性）：

- **点选、连选与框选**：鼠标左键单击仅选中条目并赋予焦点（`focusIndication` 铺底色，`commandFile` 记录当前作用项；触屏侧滑返回时由 `!pointerSource.isTouchLike` 豁免 `commandFile` 拦截，避免首次侧滑仅清除焦点而不退回上级目录，issue #30），双击才打开条目；触屏轻点直接打开。`主修饰键+单击` 切换加选，`Shift+单击` 范围连选（`selectionClicks`），网格空白处拖拽触发矩形框选（`marqueeSelection` / `selectBoxed`，瀑布流画布因手势用于连续滚动画布而不挂载框选），空白处单击退出多选。注意：桌面点选与框选传递给 `DriveScreenState` 的是列表行唯一键 `DriveListItem.File.key` 而非裸文件 ID（查重报告中同一文件或不同行实例具有独立行键，`LazyGrid` 的 `visibleItemsInfo` 同理，严禁直接当作文件 ID 使用）。是否处于多选模式由选中集合非空推导（`isSelectionMode`），唯一例外为触屏长按进入多选后即使取消勾选至 0 项仍保持多选顶栏直至显式退出。
- **应用内拖放与撤销日志**：在已选中或当前焦点条目上按住拖拽即发起应用内移动（按住 `Ctrl`，macOS 按住 `⌥` 切换为复制），可拖入网格内文件夹、顶栏地址栏各上级面包屑、宽窗口其他文件标签（自动移入该标签当前停留目录）或侧边栏快速访问文件夹；实现基于根级 `FileDragState` 与 `fileDropTarget`，不走操作系统外部剪贴板拖放（回收站、压缩包内、归档虚拟条目、上传中文件与导入虚拟预览不提供拖出）。移动、重命名、移入回收站及归档完成后均记入仓库 `DriveChangeJournal`，支持 `主修饰键+Z` 撤销最近一次操作，带「撤销」的 Snackbar 统一由主界面 `showChangeNotices` 在 `LocalRootSnackbar` 上弹出，网盘页不重复订阅。
- **键盘导航与滚轮缩放**：方向键在条目间移动焦点（键盘导航时 `focusIndication` 绘制描边，鼠标点击时铺底色），`Menu` 键或 `Shift+F10` 打开上下文操作，`Delete` 移入回收站，`F2` 重命名，鼠标前后侧键对应后退与前进。`主修饰键+鼠标滚轮`（Windows 触控板双指捏合因系统映射为 `Ctrl+滚轮` 同样生效）沿 `列表 -> 海报墙小 -> 中 -> 大` 逐档缩放（位于瀑布流画布内时则在其自身小/中/大三档间缩放；`DriveZoom.kt` 每次直接串联读写偏好存储而非依赖当前帧 UI 状态，确保单帧内连续多格滚轮不会丢失步数；海报墙与瀑布流各自独立保存设备本地卡片尺寸偏好，视图模式本身跨设备同步）。平台差异键位：
  - **Windows / Linux**：`Enter` 打开条目，`Alt+Enter` 查看属性（条目层 `onPreviewKeyEvent` 拦截），`Backspace` 或 `Alt+←` / `Alt+→` 后退与前进，`Alt+↑` 返回上一级。
  - **macOS**：`⌘↓` 打开条目，`Enter` 重命名（条目层 `onPreviewKeyEvent` 先行拦截），`⌘[` / `⌘]` 后退与前进，`⌘↑` 返回上一级。
