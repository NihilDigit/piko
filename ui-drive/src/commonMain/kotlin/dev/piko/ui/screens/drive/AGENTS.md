# 网盘页

通用界面约定见 `../../../../../../../AGENTS.md`（即 `ui/AGENTS.md`），核心列表状态位于 `shared/.../shared/state/DriveScreenState.kt`。宽窗口与窄窗口严格按实际可用净宽高与内容容量划分，不按平台划分；文件浏览、链接导入与查重共享同一套账号工作集合（`WorkspaceContexts` 与 `DriveWorkspace`），触屏、鼠标与键盘可随时混合操作。

## 视图、特殊位置与探索模式

### 瀑布流画布（`GallerySession` 与 `GalleryCanvas`）

- **作用域与增量发现**：普通目录视图切换保留「列表」与「海报墙」两种当前层视图；「瀑布流」与「信息流」同为面向当前目录子树（或多选模式下显式选定的视频集合）的探索入口。`GallerySession` 归属 `DriveBrowserSession`，切换标签、切往任务页或调整窗口尺寸均保留已发现列表与浏览进度；仅在切换目录、开启搜索或显式确认关闭时退出。普通目录通过 `VideoDiscovery` 与仓库 `listBrowsable` 逐层发现视频（沿用归档虚拟条目合并与内部目录隐藏规则；包含短视频，不套用信息流的 60 秒时长门槛或启发式样片折叠）。每次请求至多扫描 16 个目录、追加 48 个视频，视口接近尾部时自动触发下一批，不设条目计数与手动「继续查找」按钮；失败目录保留为可重试状态，不计作扫描完成。候选按文件 ID 及 `GCID + 大小` 去重后经 `selectSpreadCandidates` 分散目录与作品，不按转码状态或根层优先排序。仓库 `folderChanges` 到达时增量刷新受影响目录，保留已展示顺序并将新增视频追加至末尾，移出当前子树的条目即时剔除。
- **循环带虚拟化 `Layout`、三视图外观自定义（`DriveAppearancePrefs`）、确定性缩略图缓存键（`ThumbnailCacheKey`）与防窥离屏模糊**：`GalleryCanvasLayout` 负责纯几何计算与 occurrence key（含可选 `extraTileHeight` 为封面下方标题/详情行留高），卡片等宽，按视频宽高或实测封面比例归入横向 `16:9`（含 `21:9`）、竖向 `9:16` 与方形 `1:1` 三种形状；`GalleryCanvas` 采用标准 `Layout` + `derivedStateOf` 虚拟化可见槽位列表（彻底取代 `SubcomposeLayout`，规避桌面端弹层销毁崩溃并消除同可见集内的无谓重组，滚动达边界时精确回传已消费增量不空转），相邻栏错开半个横向卡片节距，内容不足时仅补淡色品牌 Glyph 几何占位（不画底色与边框），仅组合当前视口及每栏上下各一张缓冲卡片；滚动中不向 Snapshot 写状态（`GalleryCanvas` 与 `SelectionClicks` 均避免在高频滚轮/指针事件里写入 Compose 状态）。列表（`FileListItem`，默认 `ListViewStylePrefs.folderStyle = FolderStyle.MINIMAL_ICON`）、网格（`PosterCard`，仅在开启 `DetailField.ITEM_COUNT` 时渲染文件夹条目数）与瀑布流（`GalleryCanvas`，仅展示媒体条目不含文件夹）统一读取根部注入的 `LocalDriveAppearancePrefs`（在设置顶层「自定义 -> 文件外观」经点按预览区直接操控配置并跨设备同步），独立定制拟物/极简文件夹形态、四角徽标槽位（自动去重并与封面下方状态/详情行严格 DRY 去重）、标签/次要原名、紧凑密度、有序详情字段（`.tabular` 等宽数字）以及缩略图缩放模式 `thumbnailScale`（`CROP` 裁切填满 / `FIT` 完整显示配中性底色）与清晰度 `thumbnailClarity`（`LOW` `256px` / `STANDARD` `512px` / `HIGH` `1024px` 并尝试将 PikPak 缩略图提升至 `/720/2048`，缺失时一次性回退）。缩略图请求与预取统一经 `ThumbnailCacheKey.kt` 生成跨重启确定性 `memoryCacheKey` 与 `diskCacheKey`（将 PikPak 区域 CDN 缩略图归并为 `pikpak:<kind>:<GCID>` 并剥离 `Expires`/`Signature`/`token`/`e`/`sig` 等易变签名参数；`LOW` 与 `STANDARD` 共用 `sd` 档磁盘缓存，`HIGH` 独立 `hd` 档；文件夹容器 ID 不纳入 `stableId` 以确保封面更换即时失效；磁盘缓存上限为桌面 `512 MiB` / Android `256 MiB`）。本地索引构建提示条（`TreeIndexProgressBanner`）采用带 `1dp` `outlineVariant` 描边的圆角状态条、左侧 `Icons.Outlined.Sync` 与简短阶段标题、右侧永不截断的 `.tabular` 计数及底边 `2dp` 进度条（受减少动画与窗口可见性门控）。首屏未滚动前实测封面比例可修正初始几何，一旦开始滚动、追加候选或从播放器返回恢复锚点（`GalleryAnchor`）后，比例更新仅作用于未访问区间，已浏览区域绝不重排。封面预取（`GalleryCanvas`）带轻微防抖并跳过当前视口内正由 `AsyncImage` 高优加载的卡片（保留条件 `id in windowIds && id !in visible`）：已知宽高比的条目使用 Coil `BlackholeDecoder` 配合 `CachePolicy.READ_ONLY` 仅预热磁盘缓存，跳过位图 CPU 解码；未知宽高比的条目仅按小尺寸探测像素解码学习比例，同时桌面端 `DesktopImageLoader` 已调高单主机并发上限以消除高延迟线路排队。海报墙卡片（`PosterCard`）与列表行（`FileListItem`）均采用零协程悬停（`PointerInputNodes`）、平滑选中态配色与正向限幅圆角变化、`1dp` `FixedColors.HudSpecularBorder` 封面描边与底部微光遮罩，且受 `LocalPikoMotion.current.reduced` 门控。缩略图防窥模糊通过 Coil3 `SpoilerBlurTransformation` 经 `PikoPlatform.blurCoilBitmap` 在解码阶段一次性完成离屏高斯/盒式模糊（严禁在滚动列表卡片上叠放逐帧实时 GPU `Modifier.blur`；模糊失败时保持 fail-closed 不泄露明图）。跨子目录视频的操作菜单置顶提供「在网盘中显示」，递归视频的命令动作读取 `GallerySession` 补充列表中的真实父目录，绝不将递归发现列表写回普通目录的 `state.files`。点击网盘、压缩包或任务页中的音频文件（`isPlayableAudio()`）直接进入 `ListenScreen` 听音频模式，并按同目录音频列表组建独立播放队列。

### 资料库（`Screen.Library`）与压缩包内浏览（`ArchiveLocation`）

- **资料库**：最近添加、星标（自动合并服务端星标真实文件与 `VaultStars` 自管的星标归档虚拟条目）、播放历史与回收站作为应用返回栈中的 `Screen.Library` 独立压栈，各自拥有独立的 `DriveBrowserSession` 保存路径栈、历史、多选与滚动锚点，不改写工作区文件标签位置，返回即回到来源页。资料库根层使用 `DriveLibrary` 虚拟路径拉取对应接口，禁止新建、上传、粘贴或拖放写入；资料库内的真实文件保留「复制到…」能力；最近添加与播放历史支持「移除记录」，回收站仅提供「恢复」与「彻底删除」（单击回收站条目弹出操作面板而不直接执行单一动作）。「在网盘中显示」压入独立定位浏览页或跳回主文件区高亮目标。「我的分享」列举分享链接而非文件，由独立页面 `Screen.MyShares` 承载。
- **压缩包只读浏览**：单击非分卷的 `zip`、`rar`、`7z` 直接作为虚拟位置（`ArchiveLocation`，ID 前缀 `piko-archive:`，携带包文件 ID、GCID 与包内相对路径）进入浏览，不再直接触发整包下载（分卷压缩包因服务端不支持列出与解压，仍走下载）。状态由进程级 `ArchiveBrowser` 持有，已验证密码与已列出层级不随页面重建丢失；需要密码时先静默逐个尝试 `ArchivePasswordVault` 中已保存的密码，全部失配才弹窗询问，取消输入即退出该包。持久化文件标签与最近访问路径时自动截断至压缩包外层父目录，重启应用不停留在包内。包内条目仅支持打开、下载单文件与解压所选项（页面主操作为「全部解压」，落点为压缩包同级目录）；打开或下载包内文件与归档条目共用按 GCID 租约借出链路（`LeasedFile`），从未在服务端解压过的压缩包首次借出文件时自动执行一次数秒的引导预热（`ArchiveRepository.prime`，延迟 400ms 显示「正在读取压缩包内容…」提示，就绪即收起），此后同一包内文件均可直接按 GCID 秒借。

### 查重报告、目录结构整理、大分享懒加载与按番号子树重命名

- **查重上下文与大规模增量扩展（`DuplicateSession`、`DuplicateFinderState`）**：每次发起查重均在 `WorkspaceContexts` 中建立拥有稳定 ID 的独立上下文（移动端对同一目录起点自动复用已有未关闭的查重会话），宽窗口经标签栏切换，窄窗口经标签总览进入完整工作页。切换页面或收起总览均不中断扫描，仅显式关闭该查重上下文（或切换账号）才停止扫描并释放报告。页眉提供「相同文件 / 不同版本」连体切换及当前分类计数，按重复组展示（`DuplicateListing`）并支持智能保留规则切换与一键勾选建议移走项。针对 3,000+ 重复组的超大结果集，`DuplicateFinderState` 仅对重复候选批量查询 `contentMetadataBatch` 与 `originalCreatedAtMillisBatch` 并在初分组后释放非重复条目的 `FileStat` 内存；后续乐观写入、删除与撤销改走 `O(重复行数)` 的增量 `filterDuplicateReport`（维持版本组代表晋升，不再全量重跑 `findDuplicates` 与正则），并配合 `DuplicateFile` 预计算字段、缓存的 `DuplicateListing` 与 `replaceSelected` 单快照选择更新。
- **目录结构整理（`FolderStructureOps` 与 `FolderStructureDialog`）**：针对已选文件夹提供「拆开 / 铺开」（`UNWRAP` 默认开启 `unwrapSingleChildChain` 单子目录套娃穿透，`FLATTEN` 递归铺平全部文件至当前目录）与「合并文件夹」（`MERGE`，需选中 2 个及以上文件夹并选择目标文件夹）。干跑阶段经 `listBrowsableStrict` 严格懒加载未访问子目录的归档清单（读取失败即中止规划，绝不当作空目录误删；网盘浏览层 `DriveListingEngine` 与 `DriveVaultAndMountOverlay` 亦从子目录 `.piko-vault-*.json` 补齐 `ChildFile` 供父级名称解析），检测目标同名冲突并提供 `SKIP`（跳过冲突项且绝不将含跳过项的祖先目录移入回收站）与 `RENAME_SUFFIX`（自动追加编号后缀）两种策略；执行阶段对真实文件与归档虚拟条目统一调度（`moveVaultEntries` 按已提交清单先写目标再删源，未匹配项标记祖先失败保护原目录不被移入回收站）。打开对话框与提交执行前均校验 `ReceivingActivity` 路径锁（覆盖当前活动目录与目标目录），所有重命名、移动与空壳移入回收站均经 `PikoDriveRepository`（`applyChange`）统一收口。
- **大分享懒加载与超大列表防崩（`ShareTreeBrowser`、`CompactIndexSelection`）**：分享链接导入由 `ShareTreeBrowser`（按目录级 `Mutex` 懒加载分页、`ShareTreeList` 展开即拉与 `LoadMoreRow` 内联重试）取代原有的 64 目录热爬；勾选状态采用 `O(1)` 继承覆盖模型（超大磁力列表同步使用极性翻转的 `CompactIndexSelection` 与大树默认折叠上限）。整选的未展开分享文件夹直接调用服务端 `restoreFromShare`（零子目录爬虫、按 100 分批转存），嵌套半选（`INDETERMINATE`）目录链自顶向下经 `createFolder` 物化以保留原始目录层级不扁平化；「以引用保存」采用仅在目录树页扫描阶段持有 `PikoMemoryGovernor` 许可、单文件夹批次上限 `25,000` 的有界流式遍历（回调外部落盘前释放 `TreeBuild` 许可以避免与 `SnapshotWriter` 死锁），彻底消除 64 目录 / 20 页硬上限。
- **普通编辑与递归批量重命名**：移入回收站、移动、恢复、永久删除按服务端 500-ID 上限并发提交，星标按 100-ID 上限提交。整批先投影，成功子集合并为一条撤销记录，失败只撤回对应投影；不创建任务页卡片。批量重命名（`BatchRenameDialog`）顶栏在存在当前目录 `pwd` 时提供「包含子目录」开关（`OutlinedToggleButton`，经独立可取消子作用域运行 `CanonicalTreeScan(includeRoot = false)` 递归扫描子树并通过 `copyDraftFrom` 保留已编辑规则草稿，兼容真实文件与归档虚拟条目）与规范命名继续使用模态对话框内进度。
- **按番号规范命名文件夹（`CanonicalFolderRenameDialog`）**：在模态对话框内执行子树扫描（`CanonicalTreeScan`），扫描完毕即就地转为固定套用番号规范规则的批量重命名预览（`BatchRenameState` 的 `tree` 模式），支持逐项取消勾选或微调新名称，关闭对话框即放弃本次扫描，不创建后台会话或工作标签。单个带番号文件的规范命名不单独占用右键菜单项，直接集成在普通「重命名」对话框底部（预填规范名，已配置 MetaTube 时同一常驻行无缝切换为拉取片名按钮，保持对话框高度恒定）。

## 命令栏、顶栏、目录图与属性浮卡

### 命令栏与顶栏

- **宽窗口命令栏、紧凑筛选条与多选浮动工具栏（`DriveCommands.kt`、`DriveExplorerBars.kt`、`DriveChrome.kt`）**：宽窗口命令栏遵循 M3 Expressive 三级视觉强调阶梯并统一 `36dp` 控件高度与 `1dp × 18dp` 组间细分隔线（`BarDivider`），仅放置**作用于当前目录位置**的命令：新建（Tier 2 Tonal `SplitButtonLayout` 分体按钮 `NewActionSplitButton`：主段一键新建文件夹，尾段下拉菜单承载上传文件/上传文件夹/挂载等 `actions.drop(1)`，不重复列出主动作）、粘贴、排序、类型筛选（Tier 3 `onSurfaceVariant` 文字按钮，激活态以 `secondaryContainer` 胶囊高亮）、查找重复（固定附带文字标签以区分「复制」图标）、按番号规范命名、多选模式下的全选（多选时左端「新建」替换为退出多选与等宽 `.tabular` 已选计数/总容量）、刷新、视图切换与瀑布流/信息流连体开关（`OutlinedToggleButton` 连体组，未激活时保持轻量化描边，激活时填充 `secondaryContainer`，与查重页 `DuplicateKind` 连体切换保持一致）、回到根目录主页按钮，最右端固定放置唯一的 Tier 1 高强调填充主操作（添加链接、清空回收站、全部解压、选中建议移走项等；查重页在已选中全部建议清理项时自动收起该按钮）。紧凑窗口列表页眉在多类文件或已筛选时直接展开单行可横向滚动的 M3E `FilterChip` 筛选条（`TypeFilterChipRow`，1 对 1 取代紧凑页眉下拉按钮以保持 DRY），宽窗口则保留命令栏内 `TypeFilterButton` 以保全纵向密度。**作用于具体文件或文件夹的条目操作一律不进入宽窗口命令栏**；进入多选并选中至少一项时，工作区底部中央升起 M3E `HorizontalFloatingToolbar`（`DriveSelectionFloatingToolbar`，`standardFloatingToolbarColors()` 配柔和浮层阴影，留 `16dp` 边缘净距，覆盖手机/平板/桌面全形态）提供高频批量条目动作与「更多操作」溢出入口（通过居中竖向分隔线隔开常规动作与删除动作：查重与回收站内将删除提升为 `errorContainer`/`onErrorContainer` 带文案药丸按钮，普通目录为统一规格的 `error` 着色图标按钮，全屏唯一删除入口不重复），同时配合右键菜单与快捷键；紧凑多选顶栏仅保留退出、计数与全选，不再重复放置「操作」按钮。所有位置命令的显隐由纯函数 `driveCommands` 唯一决定，空间不足时由 `AdaptiveBar` 按固定优先级收入「更多」，拖动窗口宽度时按钮顺序不跳变。
- **标签栏、地址栏与搜索框（`DriveTabBar.kt`、`AddressBar.kt`）**：宽窗口标签栏在标签溢出（`scroll.maxValue > 0`）时于 `+` 旁呈现全部标签列表下拉菜单，固定标签左侧辅以 `2.5dp` 主色竖条强调，忙碌标签复用 `InlineLoadingIndicator`，拖拽排序位移与边缘滚动经 `graphicsLayer` + `derivedStateOf` 隔离以消除逐像素重组。宽窗口顶栏采用文件管理器样式的后退、前进、上一级按钮配可交互地址栏（`DrivePathTitle`，聚焦/编辑态呈现 `1.5dp` 动画主色外环，每段面包屑支持点击跳转、悬停展开同级子目录菜单及接收内部文件拖放；位于资料库时首段显示资料库图标与名称且后方不带 `›` 分隔符）与搜索框（`ExplorerSearchField`，聚焦态呈现 `1.5dp` 动画主色外环，内联「全盘」「停止」采用紧凑胶囊）。窄窗口顶栏以当前目录名为主标题、当前滚动所在的结构化作品分区（`SectionJumper`，点击可快速跳往其他分区）为副标题，不重复堆叠横向面包屑；路径输入、最近访问、快速访问与前进命令通过窄窗口列表页眉菜单与路径面板完整提供。

### 浮动目录图（`FolderMap.kt` 与 `FolderMapAutoHide.kt`）

宽窗口下目录图作为普通 `Layout` 承载的浮动面板（`FloatingPanel`，不使用不抢焦点即收不到键盘事件的 `Popup`）悬于文件列表之上，展示从网盘根目录起始的懒加载树（同时列出文件夹、可作为位置展开的压缩包及文件；最内层目录文件超过 3 项时仅列前 3 项并附「还有 N 个文件」展开行；不含虚拟根行，标题栏过滤框左侧提供回到根目录的主页按钮）。窄窗口通过底部 Sheet 承载同一棵 `WorkspaceTreeRow` 目录树。点击树中文件会先导航至其父目录并高亮定位，再按列表单击规则打开（确保播放列表取自真实父目录）。目录图与仓库共享列表缓存并订阅 `folderChanges` 增量刷新。

宽窗口目录图的开关、钉住与自动收起行为及时间参数均经用户逐条手测定稿，**修改任何时序数值或状态转换前必须先征得用户确认**：

- **双独立偏好**：开关状态（`folderMapOpenFlow`，由标题栏 `×`、搜索框旁树形按钮、快捷键 `主修饰键+Shift+E` 或命令面板切换）与钉住状态（`folderMapPinnedFlow`，**仅**由标题栏钉住按钮切换，拖动、输入或点 `×` 关闭重开均绝不篡改钉住状态）作为两项独立的设备本地偏好跨重启保留。
- **停靠判定与自由浮动**：拖拽标题栏松手时，若面板左沿或右沿距列表同侧边缘不超过 `48dp` 即判定为停靠（窗口缩放后重判一次，拖拽途中不判定、不磁吸；停靠左沿则随左沿对齐），四边四角均可拖拽调大小（停靠侧的边与角除外，避免压住侧边把手）。拖至列表中间区域时面板常驻展示，不自动收起；未钉住的面板拖回边缘停靠后恢复自动收起。
- **贴边把手与自动收起时序（`FolderMapAutoHide.kt`，单测 `FolderMapAutoHideTest`）**：未钉住且处于停靠态的面板闲置时收起为贴靠列表同侧边缘（避让右侧滚动条）的实体容器色阴影把手，内含目录树图标并支持 `Tab` 聚焦（无障碍标签「展开目录图」）。
  - **悬停展开**：指针在打开区内静止满 `200ms` 才触发临时展开（移动超过 `6dp` 重新计时；按住鼠标按键时不计时，防止拖拽滚动条或框选途经边缘误触弹出）。点击把手、触屏轻点、顶栏按钮、快捷键、命令面板或在把手上按回车/空格亦可触发临时展开（键盘触发时焦点自动移入树内；从外部按钮主动唤出时须等指针首次进入保持区或面板发生交互后才启动离开倒计时，避免刚打开半秒即自动收回）。
  - **离开收起**：保持区为面板四周外扩 `24dp` 连同把手区域；指针离开保持区满 `500ms` 才收起，期间移回立即取消倒计时。正在拖拽移动或调整尺寸、面板内持有键盘焦点、过滤框内有文本或持有焦点期间均锁定不收起，条件解除后重新起算 `500ms`。收起后指针必须先完全离开打开区一次才重新武装悬停检测，防止停在边缘反复弹回。上述毫秒数为意图过滤阈值，不随「减少动画」归零（减少动画仅使 `167ms` 原位淡入位移 `PikoMotion.peekEnter` 与 `83ms` 淡出变为跳切）。收起期间面板离开组合以释放开销，但过滤词、高亮、滚动位置与 `bounds` 保留在 `FolderMapState` 中，属性卡片照常按其边界避让。
  - **键盘 `Esc` 与快捷键语义**：临时展开态下按 `Esc` 或快捷键为收起回把手（焦点在面板内时 `Esc` 先将焦点归还文件列表）；钉住态下按 `Esc` 仅归还焦点，按快捷键则等同于 `×` 彻底关闭目录图（保留钉住偏好不变）。开发版可通过 `JAVA_TOOL_OPTIONS=-Dpiko.debug.folder-map=true` 启动 `:desktopApp:run` 描绘打开区、保持区与倒计时调试叠层（正式带版本号构建自动忽略）。
- **已否决的历史形态（禁止回退）**：地址栏 `›` 呼出的迷你弹层（入口隐蔽）；嵌入左侧边栏（`240dp` 宽度无法容纳多层缩进）；在文件网格旁挤压出常驻第三栏（开关导致网格反复重排且形成双导航栏并列）；与把手共用同一容器形变伸缩的细轨（形变期间拖拽落点错位）。

### 条目操作、下载画质与属性卡片

- **条目操作单一来源（`DriveActions.kt`、`itemCommands`、`operationsOf`）**：所有动作的图标、文案、分档与分组仅在 `DriveActions.kt` 定义一次，可用性统一由 `DriveCommands.kt` 的 `itemCommands` 根据当前位置（`CommandPlace`）、选中条目状态与完全归档目录表（`fullyVaultedFolders`）纯函数计算，`DriveScreen` 的 `operationsOf` 统一组装右键菜单、底部操作面板与多选操作栏，宽窄窗口共享完整能力集合（包括文件夹查重、按番号规范命名、在新标签页打开、固定到快速访问、剪切/复制、资料库内真实文件复制到、归档与取消归档、复制或打开来源链接、复制下载直链、外部播放器打开）。多选包含可播放视频时额外提供「以瀑布流浏览所选视频」与「以信息流浏览所选视频」。部分归档文件夹同时保留「归档」与「取消归档」，完全归档文件夹仅显示「取消归档」；归档虚拟条目与真实文件对齐支持单选/多选/混合批量重命名（`VaultEdits.renameAll` 与 `RenameRun` 单步撤销 `vaultReverts`）、按番号规范命名与子树扫描、跨目录移动/剪切（`VaultEntryEditCommand.Move` 先写目标清单再移源清单并附无损有序撤销 `orderedReverts`，联动 `VaultStars` 同步迁移）、下载原画、复制直链/来源、恢复到网盘及从清单移除（由 `VaultLifecycleAuditTest` 覆盖未解析清单的 `vaultListingComplete` 门控、父目录改名/移动清理与画廊会话保活）。仅点击后仍需弹窗选择目标或参数的动作保留省略号（「移动到…」「复制到…」「下载指定画质…」「下载指定段落…」），普通「下载到本地」不带省略号。
- **下载与画质选择（`DownloadLauncher`）**：当设备开启「每次下载前选择位置」（`askDownloadLocationFlow`，默认开启）且当前平台支持选目录时，普通「下载到本地」、链接/分享解析下载与视频片段截取统一先弹出轻量应用内下载确认框（`DownloadConfirmDialog`：单项展示缩略图媒体卡，多项采用 M3E `HorizontalMultiBrowseCarousel` 横向缩略图画廊并支持桌面端纵向鼠标滚轮平滑横向滑动，下方配保存位置卡片与可用空间、「更改」目录按钮及「默认保存到此位置，不再每次询问」勾选框；仅点「更改」时调起系统目录选择器原地更新路径，勾选后持久化新默认目录并关闭逐次询问）；「下载指定画质…」在 `DownloadQualityDialog` 内同屏嵌入同一保存位置区块，避免连续弹出两个模态框。关闭「每次下载前选择位置」或平台不支持选目录时，普通「下载到本地」直接使用本机默认下载画质偏好（未设置时按原画）与默认目录立即入队并跳转任务页，文件夹直接生成可见的后台目录准备任务，绝不在入队前预先递归扫描目录以判断是否含视频。「下载指定画质…」作为独立菜单项，仅在用户主动点击时弹出 `DownloadQualityDialog`（即使已设默认画质亦照常询问；单视频列出实测各转码档与大小，多文件或文件夹仅列画质上限档位；勾选「以后按此画质直接下载」才更新默认偏好并在跳转后的任务页或当前播放器内弹出确认提示）。普通下载菜单项悬停时不探测转码档，仅「下载指定画质…」与「下载指定段落…」在指针悬停或按下时调用 `prefetchDownloadQualities` 预热。归档虚拟条目、压缩包内借出对象与导入预览条目仅支持原画下载，不提供指定画质。转码档不可读或已被移除时的错误提示必须明确点明服务端主体（「PikPak 的转码文件暂不可读」「PikPak 已不提供所选画质」），避免用户误判为客户端或本机网络故障而反复重试（详见 `shared/src/commonMain/kotlin/dev/piko/shared/download/AGENTS.md`）。
- **属性浮卡（`PropertiesPane`）**：通过右键菜单末组「属性」、空白处右键「属性」（查看当前目录）、`主修饰键+I`（macOS `⌘I`）或 Windows / Linux `Alt+Enter` 打开，锁定打开瞬间的目标快照（多选时统计项数、总大小与位置），后续列表焦点或勾选变化不联动刷新内容（一次仅开一张，对新目标触发属性时原地替换内容）。顶部预览图配 `1dp` `FixedColors.HudSpecularBorder` 与微光防窥切换胶囊，归档与本机挂载状态以语义胶囊 `InspectorStatusPill` 在头部一次性呈明（下方 `DetailSection` 不再重复文案，数值统一 `.tabular`）；窄窗口由底部 `PikoSheet` 承载，中宽与桌面窗口由 `DetailHost` 居中呈现带 `islandBorderColor` 描边的自适应高度卡片（`360~440dp`），内容超长时内部滚动（已否决跟随选中实时变化的常驻右侧属性栏与悬停详情小按钮）。

## 双名称体系（显示名与真实名称）

文件或文件夹可能同时具有解析出的结构化显示名（如将目录「动画」识别为作品名 `Frieren`、单集显示为 `01`）与网盘存储的真实文件名，单一数据源为 `DriveItemName`（`shared/.../state/DriveItemName.kt`，排版组件位于 `ItemNames.kt`，严禁手写 `folderViews[id]?.title ?: name`）：

- **辨识条目处使用显示名**（两者不同时在下方另起一行小字展示真实名称）：列表行与海报卡片（取 `title`，单集不重复冠以分区头已有的作品名）、底部操作面板头部、属性浮卡、拖放浮层标签、片段下载面板、归档确认框及归档进度与结果摘要（取 `heading`，如 `Frieren 01`）。
- **标识路径与写操作处一律使用真实名称**（`FolderIndex` 与持久化路径不掺入解析名）：顶栏地址栏、工作区标签标题、窄窗口目录标题、目录选择器、目录图、重命名输入框初始值（默认自动选中扩展名之前的主文件名）、资料库与搜索结果所在位置栏、移动/复制目标目录名、查重起点与按番号重命名对话框标题。文件名解析总开关关闭时全局统一显示真实名称。
- **搜索匹配范围与大目录异步防抖**：当前目录内搜索（`listedName`）同时匹配解析显示名与真实名称；当目录条目数超过 `500` 时在 `DriveScreenState` 中自动转入后台协程防抖筛选（`80ms`）并在同目录乐观写入期间按 ID 投影既有结果，避免主线程卡顿与未过滤列表闪现；全盘搜索在 SDK 遍历与 `DriveTreeIndex` 中按真实名称（含 CJK 模糊匹配）检索。

## 鼠标、键盘与内部拖放

点击与键位遵循各桌面操作系统的原生文件管理器规范，网格空白背景提供独立右键菜单（视图模式、瀑布流开关、显示文件扩展名、刷新、粘贴、新建文件夹、上传文件/文件夹、添加链接、全选、当前目录属性）：

- **点选、连选与框选**：鼠标左键单击仅选中条目并赋予焦点（`focusIndication` 铺底色，`commandFile` 记录当前作用项；触屏侧滑返回时由 `!pointerSource.isTouchLike` 豁免 `commandFile` 拦截，避免首次侧滑仅清除焦点而不退回上级目录，issue #30），双击才打开条目；触屏轻点直接打开。`主修饰键+单击` 切换加选，`Shift+单击` 范围连选（`selectionClicks`），网格空白处拖拽触发矩形框选（`marqueeSelection` / `selectBoxed`，瀑布流画布因手势用于连续滚动画布而不挂载框选），空白处单击退出多选。注意：桌面点选与框选传递给 `DriveScreenState` 的是列表行唯一键 `DriveListItem.File.key` 而非裸文件 ID（查重报告中同一文件或不同行实例具有独立行键，`LazyGrid` 的 `visibleItemsInfo` 同理，严禁直接当作文件 ID 使用）。是否处于多选模式由选中集合非空推导（`isSelectionMode`），唯一例外为触屏长按进入多选后即使取消勾选至 0 项仍保持多选顶栏直至显式退出。
- **应用内拖放与撤销日志**：在已选中或当前焦点条目上按住拖拽即发起应用内移动（按住 `Ctrl`，macOS 按住 `⌥` 切换为复制），可拖入网格内文件夹、顶栏地址栏各上级面包屑、宽窗口其他文件标签（自动移入该标签当前停留目录）或侧边栏快速访问文件夹；实现基于根级 `FileDragState` 与懒注册 `fileDropTarget`（仅在拖拽活跃时追踪目标矩形以消除平时滚动开销），不走操作系统外部剪贴板拖放（回收站、压缩包内、归档虚拟条目、上传中文件与导入虚拟预览不提供拖出）。移动、重命名、移入回收站及归档完成后均记入仓库 `DriveChangeJournal`，支持 `主修饰键+Z` 撤销最近一次操作，带「撤销」的 Snackbar 统一由主界面 `showChangeNotices` 在 `LocalRootSnackbar` 上弹出，网盘页不重复订阅。
- **键盘导航与滚轮缩放**：方向键在条目间移动焦点（键盘导航时 `focusIndication` 绘制描边，鼠标点击时铺底色），`Menu` 键或 `Shift+F10` 打开上下文操作，`Delete` 移入回收站，`F2` 重命名，鼠标前后侧键对应后退与前进。`主修饰键+鼠标滚轮`（Windows 触控板双指捏合因系统映射为 `Ctrl+滚轮` 同样生效）沿 `列表 -> 海报墙小 -> 中 -> 大` 逐档缩放（位于瀑布流画布内时则在其自身小/中/大三档间缩放；`DriveZoom.kt` 每次直接串联读写偏好存储而非依赖当前帧 UI 状态，确保单帧内连续多格滚轮不会丢失步数；海报墙与瀑布流各自独立保存设备本地卡片尺寸偏好，视图模式本身跨设备同步）。平台差异键位：
  - **Windows / Linux**：`Enter` 打开条目，`Alt+Enter` 查看属性（条目层 `onPreviewKeyEvent` 拦截），`Backspace` 或 `Alt+←` / `Alt+→` 后退与前进，`Alt+↑` 返回上一级。
  - **macOS**：`⌘↓` 打开条目，`Enter` 重命名（条目层 `onPreviewKeyEvent` 先行拦截），`⌘[` / `⌘]` 后退与前进，`⌘↑` 返回上一级。
