新增 Linux 版、多账号、归档、目录图与压缩包浏览，下载可选画质，菜单与操作面板重新整理。

## 便携版数据位置变更

便携版的数据改存于程序目录下的 `data` 文件夹，不再写入用户目录，也不再与安装版共用。复制程序目录即可在其他电脑上使用，删除程序目录即移除全部数据。

经应用内更新升级的便携版沿用原有数据。重新下载的便携版需重新登录；旧数据位于用户目录的 `.piko` 文件夹，本机未安装安装版时可删除。

## 1.0.0 用户请注意

1.0.0 安装版升级时会重装整个程序，安装目录中自行存放的文件将被删除，请先移出。1.0.0 便携版不能应用内更新，请手动下载新版。

## 修复

- Android 版在文件名含全角或数学字体数字时，打开信息流或查找重复闪退。
- 文件夹中有无法匹配的字幕时，其中的视频无法播放。
- 压缩包密码以明文同步至网盘。现按账号加密保存与同步，已同步的明文副本会被清除。
- 网络连通性差时，在线播放缓慢、频繁中断。
- Android 版旋转屏幕后画面被拉伸。
- 文件夹改名、移动或删除后，标签页、历史与最近移动位置仍显示旧名或指向已删除的文件夹；库中的路径首段有误。
- 「在网盘中显示」有时未标出目标文件。
- 桌面端登录页输入密码时卡顿。
- Windows 版下载系统保留名（如 CON、nul）的文件失败；在非 UTC 时区安装后启动较慢。
- Windows 版设为磁力链接与种子的默认打开方式时覆盖其他应用的关联，卸载时一并删除。

## 变化

- 新增 Linux 版（x64，实验性），提供 AppImage 与 tar.gz；Windows 便携版改为 7z。
- 支持多账号切换，登录信息由系统加密保存（#11、#17）。
- 新增归档：文件夹与文件可归档为不占空间的记录，按需取回，可随时取消。秒传保存的文件记录来源磁力链接，可供复制。
- 网盘浏览：新增目录图（#18）；压缩包可像文件夹一样打开；属性改为浮动卡片；识别出作品名的条目同时显示原名，搜索时两者均可匹配；Ctrl（Mac 为 ⌘）加滚轮切换视图大小。
- 下载：可下载整个文件夹（#14）；下载视频可选画质，批量下载只需选择一次，转码画质自动转为 MP4。
- 整理：重做批量重命名，支持正则、序号与前后缀，执行前预览冲突；查找重复改为可预览、按组查看的结果页（#16）；新增按番号规范命名，初步支持接入自定义后端获取片名（实验性）。
- 操作：右键菜单与操作面板重新整理，常用操作排在顶部，其余全部列出；桌面端命令栏只保留文件夹级的命令，「添加链接」停靠在窗口右侧。
- 触控：Windows 版支持触屏与触控笔；平板与横握的手机改用与手机一致的操作方式。
- 信息流在各文件夹与作品间交替播放，新增沉浸模式与手机横屏（#15），桌面端弹出的窗口可置顶。
- 播放器新增详细信息与硬件解码开关，换集时保留画质与倍速；桌面版新增音量控件；Mac 版支持外部播放器。
- 设置页重新编排，新增「减少动画」；会员可管理 WebDAV；手机上的解压与归档进度显示在传输页，应用在前台时不再弹出进度通知。
