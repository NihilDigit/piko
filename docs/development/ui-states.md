# 界面状态表

列出 Piko 全部可达的界面状态，按桌面与移动两种交互模型对照，以及它们之间如何叠加与切换。改界面时同步更新本表；
`:shots` 的 `standardSet` 按本表逐项出图（移动端用 `--mobile`，平板横屏是 `--size 1280x800 --mobile`），
Android 特有的部分（系统栏、键盘、返回手势、横屏锁定）在真机上核对。

## 形态

交互模型按平台定（`PikoPlatform.formFactor`），宽度只调整同一模型里的密度，见 `ui/CLAUDE.md` 的响应式布局。

| 形态 | 平台 | 骨架 |
| --- | --- | --- |
| 桌面 | Windows、macOS、Linux | 侧边栏（≥ 1000dp 展开推开内容，更窄只占窄轨、展开时浮出）、外框与岛、地址栏与命令栏、标签、浮动卡片；键鼠；播放器与信息流可开独立窗口 |
| 移动 | Android 手机与平板 | 宽 < 600dp 是底部导航栏，更宽是收起的 Rail；顶栏标题加分区跳转、FAB、条目上的更多按钮、独占 sheet；触屏、返回手势、输入法 |

移动端里随宽度变的只有：导航（底栏或 Rail）、网格栏数、`PikoSheet` 的形态（expanded 或横握时从侧边出来，否则底部）、
目录选择器与批量重命名是否全屏、设置页是否分栏。下文移动一列不再区分手机与平板，除非注明。
手机横屏只在信息流与播放器两节记专门适配的画面。

Android 的 `MainActivity` 声明了 `configChanges`，转屏与分屏不重建 Activity，`remember` 的状态在转屏后保留。

## 根状态

| 状态 | 说明 |
| --- | --- |
| 初始化 | 整窗加载，恢复会话后离开 |
| 登录页 | 无账号，或启动恢复、断网重连被服务端拒绝时进入。表单限宽 400dp，两端同一张；桌面窗口按钮并入顶行。移动端返回手势退出应用 |
| 登录页（会话失效） | 预填账号名，光标在密码框，提示「登录已失效，请重新输入密码」 |
| 登录页（添加账号） | 从设置进入，左上角 × 取消，返回手势与 Esc 同取消。主界面整个离开组合，取消后重建，回到「文件」页 |
| 登录中、登录出错 | 按钮转圈、输入禁用；错误显示在密码框下，长驻到下次提交 |
| 主界面 | 以账号为键，换号时整个重建 |

登录页另有网络代理对话框。代码里没有验证码界面与「继续使用」账号列表，切换与补登都在设置里。

## 外壳

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| 导航 | 侧边栏：展开、窄轨、浮出（主修饰键+B） | 文件、传输、我的三项；底栏或 Rail；「传输」挂项数徽标（本机下载、上传、解压、归档，不含云端离线任务） |
| 侧边栏内容 | 「文件／传输」连体按钮（速度或项数，蜗牛模式强调色）、快速访问、库五项、账号行（新版本红点） | 无 |
| 外框与岛、自绘标题栏 | 有；紧凑标题栏可选 | 无 |
| 浮动卡片 | 右下角：解压（无停止）、归档与取消归档（有停止）、收起的添加链接；可整摞收成胶囊 | 无，进度列进传输页「云端」，开始时网盘页提示一次 |
| 命令面板、快捷键一览 | Ctrl+K、F1 | 只在接键盘时可开 |

## 网盘页

### 位置

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| 我的文件 | 地址栏加命令栏，标签栏常驻 | 顶栏目录名加分区跳转，排序与视图在列表页眉，位置命令在页眉的竖三点菜单，FAB 只管添加 |
| 首屏：骨架、整页失败、旧数据加 `StaleDataBanner` | 相同 | 相同 |
| 空态：空文件夹、搜索无结果、库空、压缩包空 | 相同 | 相同 |
| 库：最近添加、星标、播放历史、回收站 | 侧边栏开关，再点回原位置 | 从「我的」进入，离开即回「我的」 |
| 回收站 | 恢复、彻底删除；主操作「清空回收站」 | 多选顶栏换成回收站版；FAB 清空 |
| 查找重复结果 | 查重标签 | 压栈进入的位置，离开要确认 |
| 压缩包 | 单击进入，要密码时弹框；主操作「全部解压」 | 同 |
| 搜索：当前目录与全盘 | 常驻搜索框，Ctrl+F | 顶栏图标展开 |
| 多选 | Ctrl、Shift、框选；命令栏「已选 N 项」 | 长按进入，顶栏换成多选条 |
| 视图：列表、海报墙、图库 | 命令栏 | 列表页眉 |
| 目录图 | 浮动面板，Ctrl+Shift+E | 无 |

换目录时搜索词清空、多选退出。剪贴板（剪切、复制、粘贴）只有键鼠入口，存于仓库，换标签与换页都留着。

### 标签（仅桌面）

普通标签（Ctrl+T、W、Tab，中键后台开，拖条目到标签即移入）、查重标签（扫描中转圈，关标签即结束查重）、
信息流临时浏览的标签（第三色）。

### 面板与对话框

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| 条目操作 | 右键菜单；菜单键或 Shift+F10 打开操作面板 | 条目上的更多按钮打开操作面板，全部平铺、一屏放下，来源在头部；接鼠标时右键菜单同样可用 |
| 位置命令（查找重复、按番号规范命名当前文件夹） | 命令栏的查找重复；命令面板；文件夹右键 | 列表页眉的竖三点菜单 |
| 属性 | 浮动卡片，一次一张，可拖 | `PikoSheet` |
| 添加链接 | 右栏（与信息流互斥，信息流挂起让位、「信息流」入口置灰）；放不下右栏时为模态侧边面板；关掉即收成浮动卡片 | 独占 sheet，展开与部分展开两档，最宽 640dp |
| 查找重复 | 查重标签 | 独占 sheet；展开着扫完自动进结果页 |
| 目录选择器（移动、复制） | 居中对话框 | compact 或横握全屏，否则居中对话框 |
| 下载片段 | `PikoSheet`；改过区间关闭时先确认 | 同 |
| 新建、重命名、分享、下载画质 | 对话框 | 同 |
| 批量重命名 | 左规则右预览，窗口窄时单栏 | compact 或横握全屏；平板同桌面 |
| 库内确认、归档与取消归档确认、压缩包密码 | 对话框 | 同 |
| 图片查看器 | 全屏对话框，按钮与滚轮 | 手势翻页缩放 |

`PikoSheet` 在桌面一律是模态侧边面板；移动端 expanded 或横握时是侧边面板，否则是只有展开一档的底部 sheet。

## 传输页

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| 类别：全部、下载、上传、云端 | 岛顶标签，带计数 | 连体筛选，可横划；放不下时另起一行 |
| 首次加载、空态、某类为空 | 骨架；「暂无传输任务」加「新建离线任务」；「没有某类任务」 | 同 |
| 分段 | 进行中、需要处理、已完成、文件已删除（默认收起） | 同 |
| 多选 | 鼠标 | 长按 |
| 详情面板 | 侧边面板 | 底部 sheet；平板为侧边面板 |
| 删除所选确认 | 对话框 | 同 |

行的种类：本机下载、文件夹下载（列出中、列出失败、超额待确认）、上传（排队、哈希、上传中、暂停、完成、失败）、
云端离线任务、整包离线、秒传记录、服务端解压、归档与取消归档。

### 应用内更新

开屏提示是根层对话框，登录前后都会弹，开发版不查。对话框内：未开始、下载中（点外部与返回无效，可「取消下载」）、
已下载待重启（桌面）、等待安装（Android）、失败、不能应用内安装（「前往下载页」）、中断下载确认。
设置的关于卡片打开同一个对话框，改给「在浏览器中查看」而非「忽略此版本」。

## 信息流

### 承载形态

| 状态 | 桌面 | 移动 | 手机横屏 |
| --- | --- | --- | --- |
| 侧栏（网盘右侧一栏） | 放得下时 | 无 | 无 |
| 全屏 | 窗口放不下侧栏时，保留侧边栏 | 盖住导航 | 盖住整窗，收起系统栏 |
| 独立窗口 | 侧栏顶栏「在独立窗口播放」；关窗即收回 | 无 | 无 |
| 挂起（「继续刷」） | 「信息流」按钮上的小圆点 | 网盘页底部 `FeedResumeBar` | 同移动 |

打开那一刻取网盘页当前目录为范围；关闭即清空队列。侧栏的 × 与全屏的返回都是关闭。

### 画面

查找视频、空（遍历失败也落到这里）、预热（最多 20 秒）、正常播放、末尾等待页、缓冲、暂停、长按倍速、拖进度、
沉浸（控件全藏，单击叫回）、收藏星爆、Snackbar（「这一段打不开，已跳过」）。区域高度 < 480dp 时按横屏排。
Android 顶栏另有「横屏」按钮，锁 `SENSOR_LANDSCAPE`，离开时放开。

### 与播放器

| 场景 | 桌面 | 移动 |
| --- | --- | --- |
| 「看完整」 | 新开播放器窗口，信息流暂停 | 放开横屏锁后压栈播放器；返回时信息流重建，当前段从头播 |
| 「在网盘中显示」 | 侧栏时挂起；独立窗口时不挂起，主窗口前置 | 挂起 |
| 播放器开着时进信息流 | 两者并存，可同时出声 | 播放器压栈时进不了 |

桌面窗口跨过侧栏阈值时，信息流换位置重新组合，当前段从头播。

## 播放器

| 状态 | 桌面 | 移动 | 手机横屏 |
| --- | --- | --- | --- |
| 承载 | 独立窗口，每次播放一个，可并存 | 应用内压栈页，盖住导航 | 同移动，直接是全屏 |
| 控件显隐 | 鼠标移动唤出，离开窗口即收 | 单击切换，4.5 秒自动收；暂停、面板、出错时常驻 | 同移动 |
| 全屏 | 窗口全屏，Esc 先退全屏 | 转屏并收系统栏；返回先退全屏；平板横握进入即全屏 | 本身即全屏 |
| 上一集、下一集按钮 | 有 | 窄于 600dp 不给，只能从选集换 | 有 |
| 面板：选集、播放设置、音轨与字幕、网盘字幕、详细信息 | 侧边面板 | 竖屏 `ModalBottomSheet`，横屏侧边面板 | 侧边面板 |
| 倍速浮层、锁定、旋转 90 度、HUD | 相同；桌面无亮度 | | |
| 分享、画质下载对话框 | 就地弹出，不暂停 | 同 | 同 |
| 图片预览 | 只有顶栏 | 同 | 同 |

取流阶段：准备中（播放键转圈）、首帧前换来源（只转圈；原画换转码时提示「原画无法播放，已切换转码」）、
来源试尽（错误卡「无法播放」，返回与重试）、播放中途重连（只转圈）、重连用尽（错误卡）、续播提示条（5 秒收起）。
播完有同分区的下一集即自动换集。

## 任务占用与叠加

### 移动端（独占）

占用者三种：查找重复、添加链接、信息流临时浏览（仅挂起的那一段）。入口一律经 `TaskSlot.claim`。

| 已有 → 新开 | 行为 |
| --- | --- |
| 添加链接 → 再开添加链接 | 不问，展开原会话 |
| 添加链接 → 外部来的新链接 | 原会话非空才问 |
| 添加链接 ↔ 查找重复 | 问「结束…并…？」 |
| 查找重复（X）→ 查找重复（Y） | 问；同一目录不问，直接看结果或展开 |
| 信息流临时浏览 → 添加链接、查找重复、进压缩包 | 问「结束信息流并…？」 |
| 添加链接或查找重复 → 打开信息流 | 问 |
| 离开查找重复所在的目录树 | 问「结束查找重复？」（`leaveGuard`）；进子文件夹不算离开 |
| 换账号、「继续刷」 | 静默结束查找重复 |

切到传输、「我的」不算离开：三个底部页面各自独立，网盘页的会话留着，回来原样。
压缩包浏览、解压、归档、多选、搜索、属性、各对话框都不占槽位。展开的 sheet 收返回手势先于属性、多选与搜索。

### 桌面

`claim` 直接放行，添加链接、查重标签、解压、归档、信息流、属性卡片、目录图可同时存在。查重与添加链接仍各只有一份，
换目标时静默替换，不问。添加链接与信息流共用右栏、同一时刻只有一个：开添加链接时信息流挂起让位，添加链接停在右栏时
信息流打不开，关掉添加链接后信息流不自动继续。只有窗口放不下右栏时添加链接才是全屏模态的侧边面板，开着时点不到侧边栏与标签栏。

### 根层浮层

自下而上：页面（各页自己的 Snackbar）→ 浮出的侧边栏 → 浮动卡片 → 定位遮罩（整窗吞输入，Esc 取消）→
`PikoSheet`、`PikoDialog`、命令面板、`ClaimDialog` → 根层对话框（解压密码、外部上传去向、更新提示）。
最后两层之间按弹出先后叠放；桌面端 `Dialog` 之间的顺序未核对。

## 页面切换时保留什么

| 内容 | 切根页 | 被压栈页盖住 | 换号 |
| --- | --- | --- | --- |
| 网盘位置、滚动、标签、剪贴板 | 保留（仓库） | 保留 | 按账号换 |
| 网盘页多选、搜索结果、属性、对话框 | 丢弃 | 丢弃 | 丢弃 |
| 查重、添加链接、解压、归档、信息流会话 | 保留（进程级） | 保留 | 结束 |
| 传输页类别、选中、滚动 | 丢弃，回到「全部」 | 丢弃 | 丢弃 |
| 浮动卡片、根层对话框 | 不受影响 | 不受影响 | 卡片随会话结束 |

桌面打开播放器是独立窗口，网盘页不受影响；Android 压栈播放器使网盘页离开组合，状态照上表「被压栈页盖住」一列。

## 返回与 Esc

| 位置 | 桌面 | 移动 |
| --- | --- | --- |
| 登录页 | 添加账号时为取消 | 退出应用；添加账号时为取消 |
| 网盘页 | 依次收面板、多选、搜索，再后退 | 依次收 sheet、属性、多选、FAB 菜单、搜索，再上一级 |
| 传输、「我的」 | 先退多选，再回「文件」 | 同 |
| 设置、我的分享 | 出栈，回到打开前的页 | 出栈回「我的」 |
| WebDAV | 回设置 | 回设置 |
| 播放器 | Esc 先退全屏，不关窗 | 先退全屏，再出栈 |
| 信息流 | 侧栏与独立窗口无处理；全屏时关闭 | 关闭并清空队列 |
| 定位遮罩、解压密码框、更新对话框 | 取消、跳过、关闭（下载中无效） | 同 |

## 外部入口

| 入口 | 着陆 | 网盘页内 |
| --- | --- | --- |
| 磁力、种子、分享链接（Android intent；桌面协议、命令行、单实例转交、拖入） | 切到「文件」，收起压栈页（Android 的播放器被弹出） | 经 `claim` 开添加链接；移动端在确认框取消则链接丢失 |
| 系统分享文件、桌面拖入文件 | 根层上传去向对话框，确认后到传输页 | 默认目标取当前位置 |
| 常驻传输通知 | 传输页 | 会话留存 |
| 任务结果通知 | 只带回前台 | 不变 |
| 官方「在 App 中打开」链接 | 「文件」页并刷新 | 不经 `leaveGuard` |
| 传输页、我的分享的「在网盘中显示」 | 经 `navigateThen`，查重先问 | 换位置；见问题 2、3 |
| 桌面再次启动、托盘 | 主窗口前置 | 不变 |

桌面关主窗口时仍有传输则藏进托盘，播放器与信息流窗口不随之关闭；传完自动退出，同时关掉它们。

## 真机核对项（Android）

1. 平板横屏与竖屏：Rail、条目更多按钮与操作面板、添加链接与查重的 sheet 宽度、信息流全屏。
2. 手机竖屏：信息流全屏、沉浸、横屏锁定；「看完整」前后的系统栏与方向。
3. 手机横屏：Rail；信息流全屏收起系统栏、下滑临时唤出；挂起后的「继续刷」条。
4. 信息流全屏时外部发来磁力链接（问题 1）。
5. 播放器：全屏进出后的方向锁，再横握是否自动全屏；平板横握点「退出全屏」（问题 5）。
6. 播放器竖屏的选集与设置面板，全屏收起系统栏时是否带出系统栏；转屏时面板的形态切换。
7. 信息流播放时退到后台、来电：是否继续出声。
8. 添加链接 sheet 的输入法让位；搜索框与重命名对话框的输入法。

## 问题

盘点时发现的问题，修掉一条删一条。「已核实」指读代码确认，「推断」指尚未实机复现。

1. **移动端外部链接打开的添加链接被全屏信息流盖住。** 信息流正常展示时不算占用，`claim` 放行，sheet 画在被盖住的网盘页里。推断。
2. **从网盘页之外换位置时，附着在位置上的状态无人处理。** 移动端开着全屏信息流时切到传输页，再点「在网盘中显示」，
   `LaunchedEffect(folderStack)` 把信息流挂起，回到网盘页凭空多出「继续刷」。已核实。
3. **桌面的查重标签可能被改写成普通文件夹。** 当前标签是查重标签时从传输页「在网盘中显示」、快速访问或命令面板跳转，
   `updateFolderStack` 改写这个标签的栈，`isDuplicates` 随之为假，查重会话仍在后台，界面上没有入口。推断。
4. **添加链接的保存结果离开网盘页即丢失。** `InstantSheetState.outcomes` 无重放，只有 `DriveScreen` 收；切到传输页后保存完成，
   会话不结束，回来仍是保存前的表单，可能重复保存。切页保留会话以后这是正常路径。推断。
5. **平板横握进播放器即全屏，「退出全屏」把屏幕锁成竖屏。** 手机退出全屏后方向同样被锁，再横握不会自动全屏。推断。
6. **桌面「看完整」的播放器没有选集。** 信息流只传 `listOf(file)`；Android 重列同目录。网盘搜索结果里点开，
   桌面的选集是搜索结果，Android 是所在目录。已核实。
7. **浮动卡片的「继续」在非网盘页点击后什么都不打开。** 卡片消失，面板要回到网盘页才出现。已核实。
8. **传输页空态「新建离线任务」只切到网盘页**，不打开添加链接。已核实。
9. **我的分享在触屏上进不了多选**；传输页有长按，这里没有。已核实。
10. **命令面板与快捷键一览在无键盘的移动端打不开**，其中的命令（立即同步设置、继续刷信息流等）没有别的入口。已核实。
11. **移动端多选顶栏缺「下载」与「从历史移除」**，桌面命令栏有。已核实。
12. **外部上传的默认目标可能是虚拟位置**（星标、回收站、查重结果、压缩包），对话框未检查。推断。
13. **添加账号的取消回到「文件」页**，不回设置；登录进行中用返回手势取消，请求不停，成功后仍切到新账号。推断。
14. **返回与 Esc 在信息流的三种承载里含义不同**：全屏是关闭并清队列（沉浸中也是），侧栏与独立窗口无处理。已核实。
15. **信息流的失败没有独立界面**：遍历失败显示为「没有视频」，末尾等待页无超时。播放器换来源与重连只转圈、无文字。已核实。
16. **桌面的播放器窗口**：同一文件点两次开两个窗口；主窗口藏入托盘后传完即退出，正在播放的窗口被关掉。已核实。
17. **移动端新版本只有开屏提示**，「我的」导航项无徽标，忽略后只能进关于卡片发现。已核实。
18. **桌面替换会话不问**：已有查重时对另一目录查重、地址栏粘贴链接，静默丢弃旧的。属 `TaskSlot` 的有意设计，列此供复核。
19. **切页时各页的界面状态（传输页类别与选中、网盘页多选与搜索）全部丢弃。** 方向：状态对象提到切页之上，`SaveableStateHolder`
    按页存滚动位置，页面照旧离开组合。待定。
