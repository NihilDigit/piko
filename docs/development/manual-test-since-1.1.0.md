# Piko 自 v1.1.0 以来的变更与手测清单

范围：`v1.1.0..main`，截至 2026-10-08。之后合入的改动在发版前补进本清单。

标记约定：

- 优先级：P0 必测（核心路径或高回归风险），P1 常规，P2 边角。
- 【会员】需要 Premium 账号。【免费】需要免费账号。【消耗次数】会占用免费账号每日离线或秒传次数。【破坏】会改动或删除网盘内容，只在专用测试文件夹内做。
- 【平板】平板或横握需单独看布局。【macOS】【Linux】仅该平台有差异或仅该平台测。
- 测试前准备：一个专用测试文件夹（含子文件夹、中英文名、超长名、名含 `;` 的文件夹），其中放视频若干（含同一剧集多集、带外挂字幕）、图片、zip、rar、7z（含加密包与分卷包）、含番号命名的文件、重复文件各一组。

---

## 一、变更概要

### 新增

1. Linux x64 桌面版：提供 AppImage 与 tar.gz，AppImage 可经 zsync 增量原地更新，磁力与种子可交给 Piko 打开。
2. 多账号：已登录的账号保存在列表中，可一键切换、添加另一个账号；退出只退当前账号并切到最近用过的另一个；会话失效时预填账号名，提示重新输入密码。
3. 凭据加密保存：Windows 用 DPAPI，macOS 用登录钥匙串，Linux 用 Secret Service，Android 用 Keystore；旧版明文文件首次启动时迁移并删除。
4. 归档（vault）：把文件夹归档为只留引用的条目（不占空间），列表中标记为已归档；播放、下载、预览时按需借出内容。可「取消归档」，取消前先清点数量与空间；归档可选只处理 50 MiB 以上文件，原文件可移入回收站或永久删除，两者均可撤销；归档与取消归档可中途停止，可在后台继续，结束时发系统通知；归档文件夹旁保存可读的磁力或链接来源文件；归档标记同步到各设备。
5. 批量重命名重做：参照 PowerRename，支持文本或正则查找替换、大小写、范围、计数器、随机串、日期；默认用「积木」搭规则，可切换为正则；有前缀、后缀、编号预设与图文指南；预览标出空名、非法字符、超 1024 字节、重名与冲突；整批一步撤销。
6. 下载整个文件夹：保持目录结构，在传输页合并为一行，可整体暂停、继续、取消；免费账号超出当日下载额度时先确认。
7. 按画质下载：点「下载」时有视频或文件夹即选画质（默认选中设置里的下载画质，可设为不再询问），单个视频列出各档大小，几项一起只选级别；转码流下载后自动转封装为 MP4；片段下载可选画质，支持暂停后续传，按时间显示进度。
8. 分享与解析面板直接下载：分享文件与已收录的解析条目可直接入队下载，关闭面板后继续；分享中的视频可预览。
9. 压缩包当作文件夹浏览：单击 zip、rar、7z 进入，只读列出，可播放、预览、下载包内文件，可解压所选项或全部。
10. 目录图：桌面窄条或浮动面板，显示从根开始的目录树（含文件），可过滤、拖动、调整大小、钉住、自动收起；快捷键 Ctrl+Shift+E。
11. 属性卡片：取代常驻详情栏，经右键、操作面板、命令面板、Alt+Enter 或 Ctrl+I 打开；桌面为可拖动的浮动卡片。
12. 查找重复结果变为网盘中的一个位置：按组分区、有缩略图，可用普通的选中、打开、右键、属性；桌面在后台标签中扫描，扫描开始与结束有提示。
13. 番号规范命名：识别更多番号写法，生成 `ABC-123-C 标题-CD1.mp4` 形式的规范名；入口在批量重命名「按番号命名」预设、右键菜单与操作面板、命令面板、单个文件的重命名对话框、文件夹整树扫描（结果页）、添加链接面板与秒传保存（可设默认）。
14. MetaTube 对接：设置中填写自建服务器地址与令牌（Piko 不内置任何站点），可测试连接；规范命名可从中取标题。
15. WebDAV 管理（会员）：在设置中开关 WebDAV，复制地址，管理登录名与密码。
16. 播放器：新增详细信息面板；硬件解码开关；画质上限设置；换集时沿用所选画质与倍速；双击步长与长按倍速可设；滑动快进手势重做，进度条显示目标；竖屏标题与额外按钮整理；文件操作与播放设置分组。
17. 信息流：控件固定在滚动层之上，新增沉浸模式（隐藏全部控件，单击唤回）；手机可锁定横屏；桌面「在网盘中显示」在独立标签中打开；定位文件夹不再逐级询问服务器；同内容复用均衡。
18. Windows 触屏与笔输入：支持多点触控、捏合、笔；触屏或笔按住弹出右键菜单，菜单新增「选择」进入多选。
19. 视图缩放：Ctrl（macOS 为 Cmd）加滚轮在列表与三档海报墙间切换；图库在自身三档间切换；触控板捏合同样生效；视图菜单可直接选卡片大小；按栏数而非固定宽度排版。
20. 动效：桌面改用标准（不回弹）动效，菜单只淡入；新增「减少动画」设置并跟随系统。
21. 条目操作重排：右键菜单与操作面板由同一份定义生成，分图标行、常驻、更多三档，属性与危险操作垫底；移动端多选条新增「下载」。
22. 归档与压缩包密码跨设备同步，用账号密码派生的密钥加密；旧版明文同步项停用并清理。
23. 便携版改为 7z；便携、安装与开发版数据目录相互隔离；桌面端不再在数据目录之外留文件。
24. 骨架屏：目录选择器、字幕选择、片段下载、画质列表加载时显示骨架。
25. 添加链接面板：标出未收录条目（保存较慢），可过滤到这些条目；保存栏固定在底部；Ctrl+Enter 保存。
26. 网盘页新增「字幕」「音轨」分区（默认收起），附着的字幕与音轨可单独下载、重命名、删除。
27. 日志：保留 7 天，警告与错误另存 30 天，连续重复行折叠；覆盖更多功能的结果与失败原因。
28. 外观重做：桌面宽窗口改为「岛」布局与外框，传输页以标签分类，所有页同一骨架；对话框统一为带实心确认钮的样式；顶栏与命令栏统一自适应收进「更多」。
29. 全局交互模型改为按平台判定：桌面任何宽度都是桌面模型，Android 手机与平板共用移动模型，宽度只决定导航形态与密度。

### 变化

1. 移动端平板与横握手机：不再得到桌面布局，改为 Rail 加移动交互（条目更多按钮、独占 sheet、全屏信息流）。
2. 桌面窄窗口：侧边栏收为窄轨，不再换成移动布局。
3. 设置与我的分享在桌面压在当前页上，Esc 返回；桌面不再有「我的」页，Ctrl+3 取消。
4. 登录页在所有窗口大小下为单个居中表单；桌面输入密码不再逐字回显；会话失效时进入登录页并填好账号名。
5. 移动端同一时刻只保留一件任务：查找重复、添加链接、按番号命名共用一个底部 sheet，开始另一件或离开所在目录树时先确认。
6. 移动端解压、归档、取消归档并入传输页「云端」，开始时提示一次，底部导航「传输」挂数量徽标。
7. 600 至 840dp 窗口按大手机排版（底栏、无外框）。
8. 添加链接、操作面板、传输详情在桌面一律浮动为侧边面板，不再停靠在右栏；右栏只放信息流。
9. 免费与会员账号保存秒传结果都是真实文件，不再生成引用条目；引用条目仅由归档产生。
10. 桌面传输页每行不再有「更多」按钮；桌面长按鼠标左键不再进入多选。
11. 单击 zip、rar、7z 由下载改为进入浏览。
12. 地址栏箭头仍列一层子文件夹；库中地址栏首段显示库名与图标。
13. 单个文件按番号命名时弹普通重命名对话框；新建与重命名对话框自动聚焦，重命名默认选中不含扩展名的文件名。
14. 网盘根目录下的 `Piko-Temp` 与 `.piko` 在列表、目录树、选择器、搜索中隐藏。
15. 目录选择器不再显示 `.piko`；浮动对话框用「取消」，全屏对话框只有关闭钮。
16. 传输页桌面分类改为岛顶标签，容量条移除。
17. 播放器：竖屏标题保留；音轨、分享、下载并入设置面板；音量与亮度等读数改为视频上方半透明条。
18. 默认用 Piko 打开磁力与种子时，不再覆盖其他应用已有的关联，只在「默认应用」中供选择。
19. 应用内更新：安装版与便携版可更新自 1.0.0、1.1.0；arm64 增量更新恢复可用。
20. 桌面浮动卡片：右下角显示解压、归档、收起的添加链接，可整摞收为胶囊；片段下载不可收起。
21. 目录选择器、最近移动目标、快速访问、历史、标签随文件夹改名、移动、删除同步更新。
22. 文件夹下载写入下载位置的子文件夹；1.0.0 遗留的、位于安装目录内的下载位置被重置为 `~/Downloads/Piko`。

### 修复（1.1.0 中存在）

1. Android：文件名含数学粗体等非 ASCII 数字时，信息流进入该文件夹闪退，查找重复失败。
2. 打开含无匹配字幕的文件夹中的视频时，播放列表构建崩溃。
3. 桌面：从设置返回网盘页时任务面板状态恢复异常，整个窗口崩溃。
4. 桌面：登录页输入密码时掉帧，且逐字回显。
5. Windows：下载名为 `CON`、`nul.txt` 等设备名的文件失败。
6. Windows：「打开方式」与默认应用中 Piko 的名称过期。
7. Windows：注册磁力或种子时覆盖其他应用的关联，卸载时一并删掉。
8. Windows：DPAPI 写失败时回退为明文文件；便携目录被多个 Windows 用户使用时第二个用户登录失败。
9. 压缩包密码被明文同步到网盘 `.piko/settings-*.json`；上传凭据明文留在任务列表中。
10. 中国大陆直连线路下，云端播放首包超时导致读取缓慢并大量块失败。
11. Android 转屏时画面被拉伸。
12. 文件夹改名、移动或删除后，标签、历史、最近去过、最近移动目标仍显示旧名或指向已删除的文件夹。
13. 库内路径的首段总是写「网盘」，点击回到错误位置；库的子文件夹菜单列出库 ID。
14. 从信息流或传输页「在网盘中显示」时，目标行高亮来不及显示；非最大版本的剧集找不到行。
15. 桌面查重标签被其他跳转改写为普通文件夹，查重会话失去入口。
16. 在查重页框选，计数为「已选 2 项」却没有任何勾选，Delete 发送了无效 ID。
17. 恢复归档时翻到其他页面导致恢复中断，留下重复文件且无撤销记录。
18. 更新后路径为 8.3 短名时，更新脚本删除了新程序目录。
19. 通过 MSI 在非 UTC 时区安装后，AOT 缓存不生效（启动慢）。
20. 外部关联：Linux 窗口管理器下磁力无法交给 Piko。
21. 免费账号归档引用被误判为冲突并重传。

## 二、手测清单

### A. 电脑（Windows 为主）

#### A1. 安装、启动与数据目录

- [ ] P0 全新安装 MSI，启动，登录一个账号，退出后重启：不需要重新登录。预期：会话保留。
- [ ] P0 从 1.1.0 已登录的安装版直接覆盖更新到本版：启动后仍保持登录，下载中的任务、快速访问、标签仍在。预期：无丢失（凭据迁移）。
- [ ] P1 便携版（7z）解压到非 C 盘，启动：数据写在便携目录下的数据文件夹，不写 `~/.piko`。预期：便携目录出现数据，用户目录无新建。
- [ ] P1 便携版放在只读目录启动：弹窗说明数据去向（`~/.piko`），同一文件夹只提示一次。
- [ ] P2 同一台机器两个 Windows 用户使用同一个便携目录，各自登录：互不影响，不读写对方的文件；第二个用户在第一个运行时启动，弹窗说明数据被谁占用。
- [ ] P1 从源码 `gradle run` 的开发版与已安装版同时登录同一账号：两者不互相挤掉会话（开发版用 `~/.piko-dev`）。
- [ ] P2 运行一段时间后检查 `%TEMP%`：无 Coil 缓存、jnidispatch、hsperfdata；退出后无遗留 socket。
- [ ] P2 旧的下载位置若在程序安装目录内：启动后重置为 `~/Downloads/Piko`。
- [ ] P1 设置中「默认应用」：把 Piko 设为磁力默认，另一个应用（如下载器）原有关联不被删除；取消注册后对方仍可用。
- [ ] P1 资源管理器右键 .torrent，「打开方式」列表中名称显示为 Piko（不是英文描述）。
- [ ] P2 卸载 MSI：关联与通知注册被清理，便携版的关联不受影响。

#### A2. 登录与账号

- [ ] P0 登录页：单个居中表单，输入密码时不逐字回显，输入流畅。预期：无品牌分栏、无「继续使用」账号列表。
- [ ] P0 错误密码：错误显示在密码框下，直到下次提交；再次输入正确密码登录成功。
- [ ] P0 设置里账号区：添加第二个账号（登录页顶部有取消），登录成功后切到新账号；位置、标签、历史、剪贴板、撤销记录换成新账号的。
- [ ] P0 在两个账号间来回切换：快速访问与最近移动目标按账号各自独立，不串账号；进行中的下载在切走时暂停，切回后可继续。
- [ ] P0 退出当前账号：自动切到最近用过的另一个，没有其他账号才回登录页。
- [ ] P1 移除一个已保存账号：确认对话框确认钮为实心，移除后列表更新。
- [ ] P1 让某账号会话失效（如在官网改密码），重启：进入登录页，账号名已填、光标在密码框、提示「登录已失效，请重新输入密码」。
- [ ] P1 设置里被拒绝的账号标为「需重新登录」，点击不再空转失败。
- [ ] P1 添加账号过程中点取消或按 Esc：回到「文件」页，原账号不变。
- [ ] P2 添加账号过程中，登录请求进行时取消：不会在成功后偷偷切换（已知推断问题，观察即可）。
- [ ] P1 【macOS】登录后重启：钥匙串读取成功，不弹出重复授权；钥匙串锁定时不被当作已退出。
- [ ] P1 【Linux】有 Secret Service（GNOME Keyring 或 KWallet）时保存与读取；无时登录页不再声称加密。
- [ ] P2 断网状态下启动：不被当作登录过期而退出。

#### A3. 外壳、导航与布局

- [ ] P0 窗口宽度从 1400 拖到 700：侧边栏 1000dp 以上展开推开内容，更窄收为窄轨，展开时浮出带遮罩；全程保持桌面交互（标签栏、命令栏仍在）。
- [ ] P0 Ctrl+B 收起与展开侧边栏，重启后保持。
- [ ] P0 网盘页、传输页、设置、我的分享：顶部结构一致（岛布局），页间切换不跳变；窗口按钮在页眉末尾。
- [ ] P1 开启「紧凑标题栏」（Windows）：按钮并入内容，标题栏空白处可拖动窗口，双击最大化；窄窗口时标题与导航按钮不被挤掉。
- [ ] P1 侧边栏：「文件／传输」连体按钮在有传输时显示速度或数量；蜗牛模式开启时「传输」强调色。
- [ ] P1 设置、我的分享打开后按 Esc：回到打开前的页，不落到「我的」。
- [ ] P1 Ctrl+K 命令面板：能搜到文件夹、命令（新建、上传、视图、属性、目录图、按番号命名、同步设置、信息流）；回车执行。F1 打开快捷键一览，内容与实际一致。
- [ ] P1 对话框外观：删除、取消分享、移除账号、退出登录等不可撤销操作的确认钮为红色实心；取消为文字钮；普通确认为实心主色。
- [ ] P1 窗口很窄（约 500dp）时：命令栏、多选栏、传输页页眉的按钮自动收进「更多」，标题与窗口按钮不被挤出，不横向溢出。
- [ ] P2 深色模式下浏览所有页：色彩对比正常（批量重命名高亮块文字可读）。
- [ ] P1 右下角浮动卡片：解压、归档、收起的添加链接堆叠显示，可收为胶囊，阴影无方角裁切。
- [ ] P2 减少动画：设置中打开「减少动画」，所有切页、面板、菜单直接跳切；系统「动画效果」关闭时同样；关闭后恢复。【macOS】辅助功能「减弱动态效果」。【Linux】GNOME 关闭动画。
- [ ] P2 动效手感：右键菜单点开后立即点击不会点偏；切页无空白闪烁。
