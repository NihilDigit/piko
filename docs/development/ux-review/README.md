## 跨区域的同类问题

几份里重复出现、宜一次改掉前提的：

1. 错误原文与重复提示：服务端错误串直接显示（drive H4、shell M4）；整页错误、空态或结果页上再弹一条
   内容相同的 Snackbar（drive H4、M9，shell M3，panels M8）。
2. 显示名与真实名称不一致：解析名「Frieren」与文件夹名「动画」在海报墙、图库、地址栏、操作面板、
   目录选择器、搜索里各用一个（drive M5，panels M9；截图时还发现按显示名搜不到）。
3. 分区跳转：报告的分区与眼前内容不符、换目录后残留（drive M1）；移动端标题下像当前路径（shell M1）；
   窄窗口被截成残字（drive M10、shell L14）。移动端面包屑与文档不符（drive L11）。
4. 只有图标、彼此形似：查找重复与复制（drive H2）、回收站的恢复与彻底删除（drive H3）、卡片大小与图库（drive L5）。
5. 组件外形不统一：对话框顶部图标、设置里的提交方式、文本框外形、目录选择器与批量重命名的外壳、
   面板头部（panels M1 至 M5）。
6. 文件名截断：尾部截断丢集号（media H3）、在扩展名中间断行（drive L9、panels L5）。
7. 压缩包密码：对话框出错变高（drive M6）、「仅存于本机」与同步事实相反（panels H2）、眼睛图标语义与登录页相反
   （shell M7）、密码框与「已开始解压」同时出现（shell H1）。
8. 导航高亮：移动端在库里亮「文件」（drive M8）；桌面侧边栏同时亮两处（shell M8）。
9. 骨架与实际布局不符：我的分享（shell M2）、传输页（media L3）。

## 待定的取舍

以下几条改法取决于设计意图，动手前先定：

- 桌面 Ctrl+A 是否进入多选（命令栏换成「已选 N 项」、卡片出勾选框），见 drive H1。
- 后退、前进是否常驻并按历史置灰，见 drive M2。
- 移动端子目录的上级用面包屑还是分区跳转，见 drive L11 与 shell M1。
- 解析名作主标题时，真实名称放在哪里，见 drive M5。
- 桌面播放器是否加音量控件、是否常驻锁定按钮，见 media M5、L11。
